Python Character Substitution Encryption
A Python-based encryption project that demonstrates the fundamentals of character substitution using a randomly generated encryption key.

Features
Generates a unique character mapping.
Encrypts text through character substitution.
Supports letters, numbers, punctuation and whitespace.
Uses dictionaries for efficient character mapping.it encrypts and decrypts text messages.

Technologies Used
Python 3
Random module
String module

How to Run
Clone the repository.
Run the program:
python3 encryption.py
Enter the text you want to encrypt.
